# 受け入れテスト チェックリスト（PHASE 10）

全7院の院長・GM・社長に、導入前に**検証環境**（ダミーのデータ）で操作していただき、できたものに ✓ を付ける。
問題があったときは、画面・操作・表示された文言をメモして開発担当に伝える。

## 社長
- [ ] ログインすると社長ダッシュボードが開き、先頭に承認待ちの合計（緊急の件数）が出る
- [ ] 有給の申請を開き、残数（承認後の残数）・年5日の状況を見て承認できる。差戻し・却下は理由が無いと押せない
- [ ] アルバイト勤務（緊急ヘルプ・シフト確定後の例外申請）を承認できる
- [ ] 振休→アルバイト勤務の変更は、GMの確認が終わるまで承認できない。確認後に承認できる
- [ ] 社内規定の改定案を承認し、「公開する」でスタッフに表示される。自分で作った案は「本人承認」と表示される
- [ ] 全院の状況（院×KPI の表）を月ごとに見られ、数値から一覧へ移れる
- [ ] スタッフを登録して ID・PASS を発行できる。退職処理でログインできなくなる
- [ ] 有給の付与・残数の修正（理由つき）ができ、履歴が残る
- [ ] 長い時間ログインしたままにした後の承認で、再ログインを求められる

## GM
- [ ] GMダッシュボードで全院の KPI を見られる
- [ ] 振休→アルバイト勤務の変更を確認（承認）・差戻しできる
- [ ] 規定の改定案を作り、社長に承認を依頼できる（公開中の版との違いが表示される）
- [ ] 院長本人の振休・社長本人の規定承認の通知が届く

## 院長（7院それぞれ）
- [ ] スマホでログインでき、院のページ（会議・タスク・スタッフの残数・申請状況）が見やすい
- [ ] 自院スタッフの振休を承認できる。他院の申請は見えない
- [ ] 自分の振休を本人承認できる（「本人承認」と表示される）
- [ ] スタッフの代わりに有給・振休を申請できる
- [ ] アルバイト勤務を申請できる（勤務する人は「未定」でもよく、後から設定できる）
- [ ] 振休の日をアルバイト勤務に変える申請ができる
- [ ] 会議を登録し、開催後に議事録（参加者・議題・内容・決定事項）を提出できる。期限（開催日の3日後の23:59）が表示される
- [ ] 決定事項の担当者・期限が、担当者のタスクに出る
- [ ] 院のタスクを登録・削除でき、進み具合が見られる
- [ ] 期限の前日・当日・超過の通知が届く

## スタッフ（各院1名以上）
- [ ] マイページで有給・振休の残数、年5日の状況、自分のタスク、未確認の規定が見られる
- [ ] 有給・振休を申請でき、承認の状況が見られる
- [ ] タスクの進み具合を更新できる
- [ ] 社内規定を読んで「確認しました」を押せる
- [ ] 入力に誤りがあってエラーになっても、書いた内容が消えない

## 全員
- [ ] 文字の大きさ・ボタンの押しやすさ（スマホ）に問題が無い
- [ ] 分かりにくい言葉・表示が無い（あればメモ）
