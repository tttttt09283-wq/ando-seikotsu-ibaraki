# EHMS 開発状況

## Phase 2（2026-11-26）

### 実装したもの
- データベース（`sql/2026-11-26_ehms_phase2.sql`、本番適用済み）：店舗の別名（aliases）、取り込み用の科目 R17〜R19・R90、`ehms_employees`（スタッフ）、`ehms_employee_pay`（報酬。適用開始日つき）、`ehms_can_see_pay()`、`ehms_user_roles.can_view_pay`、設定 staffing。既存の「スタッフ別の人件費」43名をスタッフ・報酬に初期登録（合計 月10,390,195円で一致）。
- 既存シートからの取り込み（🔁 データ入出力）：日計表の院の「合計」行 → 売上4科目（保険窓口・自費・物販・保険者請求。合計＝総売上を確認）と指標（新患数・延べ来院・レセ枚数・再診数・キャンセル数）、年間予算シート → 売上予算（R90）。確認画面・締め済みの拒否・上書き（重複しない）。
- 👤 スタッフ・生産性：スタッフマスター（院・役職・雇用形態・常勤換算・直接売上の有無・在籍）、組織図から院・役職を反映、給与（今月から適用の新しい記録として保存）、雇用コスト、個人売上（台帳）、出勤日数（賃金管理表）、1日・1時間あたり売上、人件費倍率、必要売上と達成率。直接売上を持たない人は「直接売上で評価しない」。
- 🎯 必要売上根拠シミュレーター：スタッフを選ぶか条件を入力 → 雇用コスト・総固定的負担・損益分岐点・必要月間／日次／時間売上・必要患者数・現在との差・還元原資。積み上げ（給与→雇用維持→店舗→本部→変動費→利益）、自動の説明文（数値は計算結果から）、無理な目標の警告（必要時間売上＞上限）、院全体との整合。
- ⚖️ 適正人員配置：延べ来院（需要）から必要常勤換算・実人数・過不足・最大対応能力・受けきれない来院・機会損失・人件費の増減・提案。需要データのない院には採用を勧めない。曜日別の必要人数ヒートマップ（日計表の日別）。下に、従来の「組織図×予算での判定」と「組織図の問題点」。
- 計算エンジンに追加：`dailyTotalToRecords`・`employmentCost`・`productivity`・`requiredSalesText`・`requiredSalesBreakdown`・`feasibility`・`staffingByDemand`・`weekdayNeeds`（テスト4件追加）。

### 整理（重なっていた旧機能を削除）
- 旧「📈 業績」の院別×月の予算・実績表・グラフ・集計 → EHMS の全社／院別ダッシュボード・年間PLに一本化。画面は「売上・患者KPI」（KPI推移と日計表のカード）に。
- 旧「人員の適正判断」→ EHMS の「⚖️ 適正人員配置」に統合（組織図×予算の判定と問題点はその中に残す）。
- 旧「💴 人件費×3 の売上設定」（スタッフ別の人件費の編集を含む）→ 必要売上根拠シミュレーターとスタッフ・生産性に置き換え。計算（laborPlan）とテストも削除。
- 旧「💴 生産性と給与」（人材）→ スタッフ・生産性に置き換え。計算（payVsProductivity）とテストも削除。
- `hq_private_docs` の labor（元データ）は消していない（新しいスタッフ・報酬に移した元として残す）。

## Phase 1（2026-11-25）

### 実装したもの
- データベース：`ehms_*` 10テーブル・RLS・変更履歴／version／締めのトリガー・初期マスター（店舗7・科目50・事業部1・設定4）。本番の Supabase に適用済み。
- 共通計算エンジン `hq/ehms-calc.js`（PL・年間集計・予算差異・着地予測・本部経費配賦・必要売上・昇給影響・損益分岐点・人員配置・アラート）。
- 画面（本部システムのサイドメニュー「EHMS 経営管理」）
  - 全社経営ダッシュボード：月間総売上・年間累計・着地予測・予算達成率・必要平均売上・粗利・営業利益（率）・経常／税引後・人件費率・固定費率／変動費率・損益分岐点・店舗数。月別売上（実績・予算・前年）・月別営業利益・院別売上／利益・経費構成比。アラート（理由・根拠・確認・推奨アクション）。カードを押すと計算式と入力値。
  - 院別ダッシュボード：ランキング（並び替え）・配賦前／配賦後・達成率・前年同月比・人件費率・年度累計。
  - 月次PL：科目ごとに予算・実績を入力（自動保存・空で削除）、差額・達成率・前年同月・前年同月比、小計（売上高・粗利・人件費・営業・経常・税引前・税引後）。本部の行、全社（合計・入力不可）、締め済みは入力不可。
  - 年間PL・推移・着地：12か月×（実績・予算・差額・達成率・前年・前年比）、上期・下期・四半期・年間、着地予測（5方式・楽観／標準／悲観・確定実績と予測を線種で区別）。
  - データ入出力：CSV／Excel 取り込み（見出しの対応・型・必須・権限・締め・ファイル内重複の検証、プレビュー、エラー行、上書き件数、ファイルのハッシュで取り込み済みを知らせる、履歴）。CSV／Excel 書き出し（月次データ・年間PL）、ひな形、印刷。
  - マスター設定：会社（会計年度の開始月・目標値・配賦方式・予測方式）、店舗・事業部・科目の追加・変更・無効化。
  - 権限・締め・履歴：役割と担当店舗、月次締め・解除、変更履歴。
- デモモード：7店舗×24か月のサンプルを画面の中だけで生成（保存しない・実データと混ざらない）。
