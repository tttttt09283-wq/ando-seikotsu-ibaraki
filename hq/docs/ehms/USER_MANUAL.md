# EHMS 使い方

本部システム（https://ando-seikotsu-ibaraki-hq.vercel.app ）にログインし、左のメニュー「EHMS 経営管理」から使います。

## 最初にやること
1. **⚙ マスター設定**：会社の設定（会計年度の開始月・目標値・本部経費の配賦方式）と、店舗・科目を確認します。
2. **🔐 権限・締め・履歴**：GM・BM・院長・経理などに役割を付けます（社長・経営者のアカウントで）。BM・院長は担当店舗にチェック。
3. **🔁 データ入出力**：ひな形（CSV）をダウンロードし、月次の予算・実績を入れて取り込みます。または **📒 月次PL** で直接入力します。

## 画面
- **🏛 全社経営ダッシュボード**：上で年度・月・店舗（全社か院）を選びます。カードを押すと計算式と使った数字が出ます。
- **🏥 院別ダッシュボード**：院のランキング。見出しを押すと並び替え。「配賦後／配賦前」で本部経費の扱いを切り替え。
- **📒 月次PL**：店舗（または本部）と月を選び、予算・実績の欄に金額を入れると自動で保存。空にすると削除。全社は見るだけ。
- **📊 年間PL・推移・着地**：12か月の推移。「実績・予算・予算差額・達成率・前年同月・前年同月比」を切り替え。下で年間の着地予測（方式を選べる）。
- **🔁 データ入出力**：取り込み前に確認画面が出ます（追加・上書き・エラー行）。同じファイルを2回取り込んでも重複しません。
- **🔐 権限・締め・履歴**：月を締めると、その月の実績は変更できなくなります。直すときは締め解除してから。

## 取り込みファイルの形
1行目に見出し：`年月, 店舗コード, 店舗名, 科目コード, 科目名, 区分, 金額`
- 年月：`2026-07`
- 店舗：店舗コード（例 `IBARAKI`）か店舗名。空欄＝本部
- 科目：科目コード（例 `R01`）か科目名
- 区分：`実績`・`予算`・`予測`
- 金額：整数（円）。空欄の行は取り込みません（未入力とゼロを区別するため）

## デモで見る
上のバーの「デモで見る」で、サンプルの数字で画面を確認できます。データベースには保存されません。「実データに戻す」で戻ります。

## Phase 2 の画面
- **🔁 データ入出力 → 既存のシートから取り込み**：日計表の月のボタンで売上と新患数・来院数などを、年間予算のボタンで売上予算を取り込みます（確認画面のあと「取り込む」）。月の途中で取り込んでも、月末後に取り込み直せば上書きされます。
- **👤 スタッフ・生産性**：最初に「組織図から院・役職を反映」を押すと、院・役職が入ります。院長・受付など直接売上を持たない人は「直接売上」のチェックを外します。給与（月の支給合計）を変えると今月から適用されます。
- **🎯 必要売上根拠シミュレーター**：スタッフを選ぶと、その人の給与と院の数字が初期値に入ります。条件を変えると、必要な売上・内訳・説明文がすぐ変わります。
- **⚖️ 適正人員配置**：院ごとの必要人数と過不足、曜日別の必要人数。下に組織図×予算での判定と、組織図の問題点。
