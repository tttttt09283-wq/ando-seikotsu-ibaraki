# 鍼灸臨床アカデミー 開発計画（MVP）

## 1. 目的と方針

- 経穴の丸暗記ではなく「病態 → 経絡 → 取穴の根拠」を理解させる
- 1講義 =「解説 → 図解 → 臨床例 → 小テスト → 復習」の5ステップ。小テスト合格（70%以上）で講義完了
- 教材は **伝統的主治 / 現代医学的な病態 / 臨床研究エビデンス** を区別して表示
- 出典・監修状態を全教材に持たせ、未監修のものは「要確認」と明示（AIが生成した未検証情報を確定知識として表示しない）
- 症例はすべて架空の教育用症例。患者の個人情報は扱わない

## 2. 技術構成

| 項目 | 採用 |
| --- | --- |
| フレームワーク | Next.js 16（App Router, 全ページ静的生成）/ React 19 / TypeScript |
| スタイル | Tailwind CSS v4 + shadcn/ui（Radix UI ベース。`src/components/ui`） |
| 図解 | インライン SVG（React コンポーネント。座標データを TS で保持し編集可能） |
| 保存 | `LearningRepository` インターフェース + localStorage 実装 |
| 将来 | Supabase 実装を同インターフェースで差し替え（`src/lib/repository/supabase.ts` / `docs/supabase-schema.sql`） |

## 3. ディレクトリ構成

```
src/
  app/                      画面（ルーティング）
  components/
    ui/                     shadcn/ui コンポーネント
    layout/                 ヘッダー・下部タブ（スマホ片手操作）
    figures/                SVG 図解（人体模式図・経絡系統図・流注図・八脈交会図）
    lesson/ quiz/ points/   機能別コンポーネント
  data/                     教材データ（章・講義・経絡・経穴・八脈交会・症例・出典）
  lib/
    repository/             保存層（local / supabase スタブ）
    learning-store.tsx      学習状態（React Context）
    review.ts               復習スケジュール（間隔反復）
    stats.ts                集計（週次・正答率・苦手）
```

## 4. 画面構成

| パス | 画面 | 主な内容 |
| --- | --- | --- |
| `/` | 学習ダッシュボード | 今日の講義・前回の続き・進捗・習熟度・要復習・学習時間・正答率 |
| `/curriculum` | カリキュラム一覧 | 全10章、章ごとの講義と進捗、公開状態 |
| `/curriculum/[chapterId]` | 章詳細 | 章の到達目標・講義一覧 |
| `/lessons/[lessonId]` | 講義 | 5ステップ（解説→図解→臨床例→小テスト→復習）、ステップ進捗バー |
| `/meridians` | 経絡マップ | 前面/後面/側面切替、十二経脈の表示切替、流注・所属経穴・表裏・接続、経穴タップで詳細 |
| `/points` | 経穴辞典 | 検索・経絡別・要穴別フィルター・お気に入り |
| `/points/[code]` | 経穴詳細 | 位置/取穴/局所解剖/要穴分類/主治（区分別）/配穴/安全/出典・監修状態 |
| `/eight-confluent` | 八脈交会穴 | 4組の接続図、奇経・循行・病候・配穴根拠・左右の考え方・臨床例 |
| `/cases` `/cases/[id]` | 症例演習 | 危険徴候→鑑別→経絡→証→治則→経穴→評価の7段階判断と根拠解説 |
| `/progress` | 学習記録 | 講義完了状況・テスト履歴・間違えた経穴・苦手理論・復習予定・週ごとの成長グラフ |

ナビゲーション：スマホは画面下部の固定タブ（ホーム / カリキュラム / 経絡マップ / 経穴辞典 / 記録）、PC は上部ヘッダー。

## 5. MVP の範囲

1. 学習ダッシュボード
2. 全10章のカリキュラム一覧（第2章 第1講「経絡とは何か」を完成教材として公開。他講義は「準備中」）
3. 「経絡とは何か」の完成教材（5ステップ）
4. 十二経脈の基本的な模式図（仮図であることを明示）
5. 八脈交会穴8穴の辞典
6. 小テストと学習履歴保存（localStorage）
7. スマホ対応

追加で、八脈交会穴の学習画面と症例演習1例を MVP に含める（辞典データを再利用できるため）。

## 6. データ品質ルール

- 経穴位置は WHO 標準経穴部位（2008）と国内教科書の記載に準拠することを目標とし、各項目に出典IDを付与
- `reviewStatus`: `unverified`（要確認） / `in-review`（監修中） / `verified`（監修済み）
- 主治は `traditional` / `modern` / `research` の3区分。研究エビデンスが未登録のものは「登録なし」と表示
- 初期データはすべて `unverified`。監修者の確認後に更新する
