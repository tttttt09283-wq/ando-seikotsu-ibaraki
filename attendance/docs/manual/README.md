# 運用マニュアル（あんど整骨院グループ 勤怠管理システム）

| マニュアル | 対象 | 内容 |
|---|---|---|
| [本部事務](./hq.md) | 本部事務・システム管理者 | 初期設定、日々の確認、一括承認、有給・振休、月次締め、帳票出力 |
| [院長](./manager.md) | 院長 | シフト作成・確定・変更、日々の勤怠確認、打刻修正、休暇・振休、月次の院長確認 |
| [スタッフ](./staff.md) | 一般スタッフ | 共用端末での打刻・休暇申請、PIN、困ったとき |
| [共用端末の設置](./kiosk-setup.md) | 本部・院長 | タブレットの準備、端末登録、固定設定、通信障害時 |

## 1か月の流れ

```
月初〜月末  院長：シフト作成・確定 → スタッフ：共用端末で打刻
            院長：毎日の勤怠確認・打刻漏れの修正申請 → 本部：打刻修正・休暇・振休の承認
翌月1〜3日   院長：前月の「月次の院長確認」
翌月3〜5日   本部：未解決を確認 → 月次締め（院別・全院一括）→ 帳票出力 → 給与計算へ
必要時       本部：理由を入力して締めを再開 → 修正 → 再締め
```

日付は日本時間です。打刻はサーバーの時刻で記録され、端末の時計を変えても打刻時刻は変わりません。
