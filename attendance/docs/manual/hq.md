# 本部事務マニュアル

## 1. はじめに：権限

| できること | 本部事務 | 院長 |
|---|---|---|
| 全院のシフト・勤怠・有給・振休の閲覧 | ○ | 担当院のみ |
| 打刻修正・休暇・振休の最終承認 | ○ | 一次承認・報告まで |
| 月次締め・再開 | ○ | ×（院長確認まで） |
| 休日管理（出勤区分・有休の付与方式）・賃金管理 | ○ | × |
| 帳票出力 | 全9種・全院 | 勤怠の4種・担当院のみ |
| スタッフ・店舗マスタ・アカウント | ○ | 閲覧のみ |

操作の履歴（誰が・いつ・何を）はすべて監査ログに残り、削除できません。

## 2. 初期設定（最初に1回）

1. **店舗マスタ**（`店舗マスタ`）：7院は登録済み。院名変更・休止・閉鎖はここから。院名を変えても過去の勤怠は残ります。
2. **診療時間・法定休日**（各院のページ `/clinics/院ID`）：院ごとの曜日別診療時間、法定休日を登録します。
   - 法定休日が未登録の院は、法定休日労働を判定しません（画面に「法定休日が未登録」と表示）。確認でき次第登録してください。
3. **会社カレンダー**：祝日（2026〜2027年は登録済み）と会社指定の休業日。振休の対象日はここで決まります。
4. **スタッフ登録**（`スタッフ`）：スタッフID（4〜8桁）、氏名、入社日、主所属院。応援先の院は「応援先を追加」。
5. **勤務条件**（スタッフ詳細の「勤務条件」）：雇用形態、週の所定日数・時間（基本は週5日・1日8時間）、**みなし残業**（正社員は基本24時間、人により変更）。
6. **アカウント**（`アカウント・権限`）：院長に「院長」ロールを院ごとに付与。
7. **共用端末とPIN**：[共用端末の設置](./kiosk-setup.md) を参照。
8. **有給残数の取込**（`有給台帳` → 取込）：今の出勤簿（Excel）をそのまま取り込めます。
   - Google スプレッドシートは「ファイル → ダウンロード → Microsoft Excel（.xlsx）」で保存してから選びます。
   - 最新月のシートを自動で選び、その月末の「有給残」を取り込みます。氏名で照合し、未登録の人は飛ばします。
   - 初回は入社日から付与日を推定して振り分けます（確認画面で確認）。最新の表で何度取り込み直しても、差分だけが調整されます。
9. **休暇の設定**（`/admin/leave-policies`）：半日・時間単位年休、祝日勤務の振休の付与条件（半日勤務＝4時間以下は0.5日）と期限。

## 3. 毎日の確認（本部ダッシュボード `/hq`）

- **本日の出勤状況**：院ごとの出勤予定・出勤済・退勤済・**未打刻**・遅刻・早退。未打刻の人は名前が出るので、院長に連絡します。
- **承認待ち**：打刻修正・休暇・振休の件数。太字は本部の対応待ちです。
- **勤怠集計**：期間を指定して実働・残業・深夜・遅刻・打刻漏れなど。院名を押すとスタッフ別、スタッフ別ではみなし残業の超過も表示（1か月単位のとき）。
- **月次締め状況・残数一覧**：有給・振休の残数。期限7日以内の振休は赤字。

## 4. 承認（`一括承認` `/hq/approvals`）

- 全院の **打刻修正**・**休暇の最終承認**（院長の一次承認済みのもの）・**振休**（院長の報告済みのもの）を一覧で確認し、チェックしてまとめて承認します。
- 1件ずつ通常の承認と同じチェックを行い、承認履歴も1件ずつ残ります。承認できなかった申請は赤く表示され理由が出ます（例：締め済みの月、残数不足）。
- 却下・内容を見て判断したいものは、各院の画面（`休暇申請` `振休` `勤怠 → 打刻修正`）から個別に処理します。

## 5. 有給・振休

- **有給台帳**（`/hq/leave`）：残数、申請中、年5日の取得義務（不足は赤字）、付与予定。付与日が来たら出勤率8割を確認して「付与」。期限切れは「失効処理」。
- **スタッフ別の台帳**（台帳の氏名を押す）：手動付与・調整（理由必須）。振休の付与対象（完全週休2日制などは対象外）もここで設定します。
- **振休・代休**：祝日勤務（振休）・休日出勤（代休）で当日休めなかった分を院長が報告 → 本部が承認すると付与（全日1日・4時間以下は0.5日）。期限は振休が原則その月末、代休が原則1か月。期限の変更・失効処理は本部のみ。
- 振休を付与した後に勤怠が修正されると「不整合」として表示されます。内容を確認して取消・調整してください。

## 6. 休日管理（本部のみ・`休日管理`）

今の「勤怠管理表（1人1ファイル）」をシステムで管理します。院長・スタッフは見られません。

1. **最初に取込**（`休日管理 → 勤怠管理表（Excel）を取り込む`）
   - 全員分のファイルを Google ドライブの1つのフォルダに入れ、フォルダごと「ダウンロード」した **zip をそのまま選択**します（複数ファイル・フォルダの選択も可）。
   - ファイル名の氏名でスタッフに照合し、日ごとの区分・有休の基準日・振休/代休の残りを確認してから取り込みます。何度取り込み直しても同じ結果で、画面で手入力した日は上書きしません。
2. **日々の管理**：スタッフを選ぶと1年分（基準日の月から12か月）が今の表と同じ並びで出ます。区分を選ぶとすぐ保存されます。
   - **法定内**（法定休日）・**法定外**（法定外休日）は勤怠の計算に使われます。法定内の日の勤務は法定休日労働（割増35%）、法定外の日の勤務は所定休日労働になります。
   - 「休みを一括で区分」：確定シフトの休みで区分の無い日を、選んだ曜日は法定内、それ以外は法定外にまとめて区分します。
   - **給与変換**：休日出勤を代休にせず給与で支払う日。代休の候補になりません。
   - （ ）内の薄い文字はシステムの記録（シフトの休み・承認済みの休暇・休日出勤・欠勤など）の参考です。
3. **有休の付与方式**：スタッフごとに「入社日基準」か「基準日方式」（例：毎年12月1日）を選びます。基準日方式の最初の付与日は入社6か月後以前にします。有給台帳の付与予定はこの方式で計算されます。
4. **Excelで出力**：今の勤怠管理表と同じ形で出力できます（そのまま取込にも使えます）。

## 7. 月次締め（`月次締め` `/hq/closings`）

1. 翌月の初めに、各院の院長が前月の「月次の院長確認」を行います（状態が「院長確認済み」になる）。
2. 締めの画面で院ごとの未解決を確認します。
   - **赤字（締められない）**：再計算待ち、打刻修正の承認待ち、休暇の承認待ち。先に承認・再計算をしてください。
   - **黄色（院長が理由付きで確認したもの）**：打刻漏れ・未確認。履歴の「理由」を確認します。
3. 締める院にチェックして「選択した院を締める」。全院一括で締められます。締められなかった院は理由が表示され、他の院は締まります。
4. 締めた月は、勤怠・シフト・打刻修正・休暇が**誰にも変更できなくなります**（システムが拒否します）。
5. 修正が必要になったら「締めの再開」に**理由を入力**して再開 → 院長・本部が修正 → もう一度締めます（再締め）。再開・再締めの履歴と締め時点の集計はすべて残ります。

## 8. 帳票出力（`帳票出力` `/exports`）

| 帳票 | 内容 |
|---|---|
| 全院月次勤怠一覧 | スタッフ別の月間集計（給与計算用：実労働・法定時間外・みなし超過・深夜・休日労働・遅刻早退・欠勤・有給取得・振休使用） |
| 院別月次勤怠一覧 | 院ごとの合計と締め状態 |
| スタッフ別勤怠明細 | スタッフ・日ごとの出退勤・休憩・労働時間・異常 |
| 有給残数一覧 | 残数・申請中・直近の付与・年5日の取得状況 |
| 有給付与・取得履歴 | 対象月の付与・取得・取消・失効・調整 |
| 振休残数一覧 | 残数・申請中・最も近い期限 |
| 振休付与履歴 | 対象月の付与・使用・失効・取消 |
| 勤怠異常一覧 | 打刻漏れ・欠勤・遅刻・早退・休憩不足・再計算待ちなど |
| 月次締め状況一覧 | 院ごとの院長確認・締め・再開と未解決の件数 |

- 形式：**Excel（.xlsx）**、**CSV（Shift_JIS）**＝Excel でダブルクリックして開ける、**CSV（UTF-8）**＝給与ソフト等で UTF-8 指定がある場合。
- 時間は「時間（小数2桁）」です（7時間30分 → 7.5）。給与計算は**締め済みの月**の帳票で行ってください。
- 出力した記録は監査ログに残ります。個人情報を含むため、保存場所・送付に注意してください。

## 9. 困ったとき

| 状況 | 対応 |
|---|---|
| スタッフが PIN を忘れた・ロックされた | スタッフ詳細の「共用端末のPIN」で再発行（5回間違えると15分ロック） |
| 端末が「未登録」と表示される | `共用端末` で登録コードを再発行し、端末で入力。古い端末は「停止」 |
| 締めた月の修正依頼が来た | 締めの再開（理由入力）→ 修正 → 再締め |
| 退職者 | スタッフ詳細で退職日を登録（過去の勤怠・台帳は残ります） |
| 異動 | スタッフ詳細の「異動を登録」で新しい主所属院と開始日を登録 |
