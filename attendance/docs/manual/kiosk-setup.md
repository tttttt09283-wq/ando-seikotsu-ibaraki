# 共用端末の設置マニュアル

## 1. 準備するもの

- タブレット（iPad など）1院につき1台以上。電源につないだまま使える場所に設置
- 院の Wi-Fi（つながらないときは打刻を端末に一時保存し、復旧後に自動送信します）

## 2. 端末の登録（本部）

1. 管理画面 `共用端末` で院を選び **登録コード**（8文字・24時間有効）を発行
2. タブレットのブラウザ（Safari / Chrome）で `https://<システムのドメイン>/kiosk` を開く
3. 登録コードを入力 → その院の打刻画面になります
4. ブラウザの「ホーム画面に追加」でアイコンを作っておくと、開き直すときに便利です

端末は登録した院の打刻にだけ使えます。紛失・入れ替え時は、管理画面で古い端末を **停止** してください。

## 3. 打刻画面以外を開けないようにする

- **iPad**：設定 → アクセシビリティ → アクセスガイド を ON → 打刻画面でサイドボタン（ホームボタン）を3回押して開始
- **Android**：設定 → セキュリティ → アプリの固定（画面の固定）を ON
- 自動ロック（スリープ）は「なし」、画面の明るさは自動に

## 4. スタッフの PIN 発行（本部）

1. `スタッフ` → スタッフ詳細 →「共用端末のPIN」で初回 PIN を発行
2. スタッフに伝え、初回の打刻時に本人が変更します

## 5. 運用上の注意

- 端末のブラウザのデータ（Cookie・サイトデータ）を消すと端末登録が外れます。再登録には登録コードが必要です。
- 端末の時計がずれていても、打刻はサーバーの時刻で記録されます。
- 通信障害時の「送信待ち」が残ったまま端末を初期化すると、その打刻は失われます。送信待ちの件数が0になってから作業してください。
- 打刻画面には前の人の名前・PIN は残りません。画面の写真撮影・共有はしないでください。
