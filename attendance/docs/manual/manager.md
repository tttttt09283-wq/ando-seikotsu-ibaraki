# 院長マニュアル

院長は**担当院**のシフト・勤怠・休暇を管理します。他院のスタッフの個人情報は見られません（応援に来るスタッフは氏名・IDのみ）。

## 1. シフト（`シフト`）

1. 月を選び、スタッフ別一覧の欄を選んで **勤務パターン**（例：9:00〜20:00 休憩3時間）・時刻・休み を入力します。複数の欄をまとめて選んで一括入力できます。
2. 「前月コピー」で前月のシフトを下書きにできます。
3. 警告（シフト未作成・勤務時間の重複・休憩不足・他院との重複）を確認します。他院と時間が重なるシフトは登録できません。
4. 「確定」で月の下書きをまとめて確定します。**スタッフはシフトを変更できません**。
5. 確定後の変更は**理由の入力が必須**で、変更前後が履歴に残ります（`シフト → 変更履歴`）。過去日のシフトを変えると勤怠に「再計算要」が付くので、勤怠画面で再計算します。
6. 締め済みの月のシフトは変更できません（本部に再開を依頼）。

## 2. 毎日の勤怠確認（`勤怠` → 日次確認）

- 日付を選ぶと、スタッフごとに **確定シフト・打刻（原本）・実働・残業・遅刻早退・異常** が並びます。
- **打刻漏れ**（退勤なし等）は「修正を申請」から申請します（理由必須）。本部が承認すると打刻原本に追記され、勤怠が再計算されます。元の打刻は消えません。
- 問題がなければ「この日を院長確認」。打刻漏れ・再計算待ちの日は確認できません。
- 異常の例：遅延送信（通信障害で遅れて届いた打刻）、所属外の院で打刻、シフト外勤務、休憩不足。

## 3. 休暇（`休暇申請`）

- スタッフは共用端末から有給・振休を申請します。院長は内容を確認して **一次承認** または却下します。本部の最終承認で確定し、シフトに反映されます。
- 端末を使えないスタッフの分は「代理申請」できます。
- 残数は申請した時点で「申請中」として確保されます。取消すると戻ります。

## 4. 振休・代休（`振休・代休`）

1. 月を選んで「祝日・休日出勤の候補を確認」を押すと、祝日に勤務した人（振休）と休日出勤した人（代休）が候補に出ます。
2. **原則は当日（その月内）に振休を使います**。当日使えなかった場合は、理由を入力して本部（上長）に**報告**します。
3. 本部が承認すると付与されます（全日1日、4時間以下の勤務は0.5日）。期限は振休が原則その月末、代休が原則1か月です。振休と代休は同じ残数として使えます。
4. 休日出勤を代休にせず給与で支払う日は、本部が休日管理で「給与変換」にします（代休の候補になりません）。

## 5. 月次の院長確認（`勤怠` → 月次集計）

月が終わったら、前月を選んで次の手順で確認します。

1. 「この月を再計算」→ 打刻漏れ・再計算待ち・承認待ちの件数を確認し、できるだけ解決します。
2. 「この月を院長確認して本部へ」。
   - 問題のない日は自動で確認済みになります。
   - 打刻漏れなどが残っている場合は**理由の入力が必要**です（例：「9/8 の退勤は本人に確認済み、打刻修正申請中」）。
3. 状態が「院長確認済み」になり、本部が締めます。取り消す場合は「院長確認を取り消す」（本部が締める前のみ）。
4. 締めた後に修正が必要になったら、本部に再開を依頼してください。

## 6. 帳票（`帳票出力`）

担当院の **院別月次勤怠一覧・スタッフ別勤怠明細・勤怠異常一覧・月次締め状況一覧** を Excel / CSV で出力できます。
