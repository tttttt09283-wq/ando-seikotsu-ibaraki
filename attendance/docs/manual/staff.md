# スタッフマニュアル（共用端末の使い方）

## 打刻

1. 院の共用端末で **スタッフID** を入力 →「次へ」
2. **PIN**（暗証番号）を入力
3. 自分の名前を確認して、**出勤・休憩開始・休憩終了・退勤** のいずれかを押す
4. 「打刻しました」と表示され、数秒で最初の画面に戻ります

- 打刻時刻はサーバーの時刻で記録されます。
- 応援先の院では、その院の端末で打刻してください（どの院で働いたかが記録されます）。
- 同じボタンを続けて押しても二重には記録されません。出勤していないのに退勤など、順番が違う打刻はできません。
- 操作の途中で離れると、30秒で最初の画面に戻ります（名前・PINは残りません）。

## 休暇の申請

1. 最初の画面で「休暇申請」→ スタッフID・PIN を入力
2. 有給・振休の **残り日数** が表示されます
3. 種類（有給・振休）、日付、全日／午前半休／午後半休を選んで申請
4. 院長の一次承認 → 本部の最終承認で確定します

振休は、祝日に勤務した日と**同じ月のうちに使う**のが原則です。

## PIN

- 最初の PIN は本部から渡されます。**初回の打刻時に自分の PIN に変更**してください。
- PIN は4〜8桁の数字です。「1111」のような同じ数字の繰り返しや「1234」のような連番は使えません。誕生日など推測されやすい番号も避け、他の人に教えないでください。
- 5回続けて間違えると15分間使えなくなります。忘れたときは院長・本部に再発行を依頼してください。

## 困ったとき

| 状況 | 対応 |
|---|---|
| 打刻を忘れた・押し間違えた | 院長に伝えてください（院長が修正を申請し、本部が承認します）。自分では修正できません |
| 「通信できません・送信待ち」と表示された | そのまま業務を続けて大丈夫です。通信が戻ると自動で送信されます（遅れて届いた打刻として記録されます） |
| シフトを変えたい | 院長に相談してください（スタッフはシフトを変更できません） |
