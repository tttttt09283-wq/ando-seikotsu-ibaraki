# デモデータ（架空）

`demo-data.sql` は、画面確認・操作説明用の**架空のデータ**です（7院・スタッフ23名、2026年9〜10月のシフト・打刻・勤怠、9月の締め、休暇・振休・代休、休日管理の区分、賃金）。
実在の人物・金額は含みません。

## 投入のしかた（新しい Supabase プロジェクト）

1. `supabase/migrations` をすべて適用する（`seed.sql` は不要。院・祝日もデモデータに含まれる）
2. ログイン用アカウントを作る（Authentication → Users、または SQL）。デモデータの `app_accounts` / `user_roles` は次の ID を参照している
   - `62a99bf4-ecc0-4814-8286-d4ea3ded1965` システム管理者
   - `648f6311-a8ee-4693-9483-c31518cdcb9a` 本部事務
   - `bca0f614-b89f-4c16-935e-72f42f2c7767` 茨木院 院長
3. `demo-data.sql` を実行する（`session_replication_role = replica` でトリガーを止めて投入）

パスワードはこのリポジトリには置きません。共用端末は「未登録」の状態で入るので、画面の「共用端末」から登録コードを発行して登録してください。

## 本番運用を始める前に

デモデータは必ず削除し、プロジェクトを作り直すか、データを空にしてから実データを登録してください。
