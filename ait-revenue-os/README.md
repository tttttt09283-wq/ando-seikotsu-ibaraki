# A.I.T Revenue OS（ローカルMVP）

A.I.T company（理念：自由に、自分たちが楽しい）の **note デジタル商品販売** と **楽天アフィリエイト** を、
AI社員（チャドほか）と一緒に運営するための、Mac 上で動く管理アプリです。

- 調査・企画・制作・分析を AI で省力化し、**公開・販売設定は必ず人間（社長）が承認して行います。**
- 外部への投稿は **Threads の予約投稿だけ**。社長が承認し、さらに日時を予約した投稿だけを Meta 公式APIで投稿します（スイッチを入れるまでオフ）。
- note・楽天・X への投稿や販売設定の変更は行いません。スクレイピング・ブラウザ自動操作もしません。
- APIキーがなくても、テンプレートとサンプルデータで全画面を使えます。

> このフォルダは同じリポジトリ内の他のアプリ（整骨院システム・`ait-company-os/`）とは独立しています。

## 1. はじめての起動（Mac）

### 必要なもの
- **Python 3.11 以上**：ターミナルで `python3 --version` を実行して確認します。
  3.10 以下の場合は https://www.python.org/downloads/macos/ から最新版をインストールしてください。

### 手順（ターミナルで1行ずつ実行）
```bash
cd ~/ando-seikotsu-ibaraki/ait-revenue-os     # このフォルダへ移動（場所は環境に合わせて）
python3 -m venv .venv                          # このアプリ専用のPython環境を作る（初回のみ）
source .venv/bin/activate                      # 専用環境に入る（毎回）
pip install -r requirements.txt               # 必要な部品を入れる（初回のみ・数分）
cp .env.example .env                           # 設定ファイルを作る（初回のみ）
streamlit run app.py                           # 起動
```
ブラウザが自動で開きます。開かない場合は **http://localhost:8501** を開いてください。
終了するときはターミナルで `Ctrl + C` を押します。

### 2回目以降
```bash
cd ~/ando-seikotsu-ibaraki/ait-revenue-os
source .venv/bin/activate
streamlit run app.py
```

### AI生成を有効にする（任意）
1. https://console.anthropic.com で APIキーを発行します。
2. `.env` ファイルを開き、`ANTHROPIC_API_KEY=` の後ろにキーを貼り付けて保存します。
3. アプリを再起動します（左のサイドバーに「AI：有効」と表示されます）。

`.env` は Git に保存されません（`.gitignore` 済み）。キーを他人に見せたり、チャットに貼ったりしないでください。

## 2. 使い方（基本の流れ）

アプリを開くと最初に **「✅ 今日やること」** が表示されます。全部門の状況から、今日対応すべきことが優先度順に並び、
「社長がやること」と作業時間の目安もわかります。ここから各画面へ移動して、上から順に片付けてください。

### 集客ハブ（📡）
SNS（Threads・Instagram・X・LINE公式・Facebook）、Googleマップ（MEO）、Web検索（SEO）、AI検索（AIO）、note・楽天を1画面のカードで管理します。
- Threads・note販売数・楽天報酬・AI検索の言及率は自動集計、それ以外は各管理画面の『過去7日間』の数字を週1回転記します（自動取得・自動投稿はしません）
- **検索対策**：SEO・MEOの順位、AI検索（ChatGPT・Gemini 等）で自社が言及されたかを記録
- **口コミ対策**：口コミを記録し、AIが返信の下書きを作成（返信はGoogleマップ等で自分で投稿）
- **AI分析**：集客データ分析 → 課題を可視化 → 改善ポイント

### Threads → note 販売の流れ
1. **🧵 Threads運用 › 分析**：投稿の反応（閲覧・いいね・返信など）を同期し、伸びた投稿の特徴（時間帯・文字数・1行目など）を確認
2. **🤖 AI改善案**：マーケティングAIが「伸びた型」で次の投稿案を作成 → 下書きとして保存
3. **承認キュー**で承認 → **Threads運用 › 予約投稿**で日時を予約（おすすめ時刻を自動表示）
4. 予約時刻に **scheduler.py**（予約投稿の実行係）が公式APIで投稿し、URLと反応数を自動記録
5. **🛤 note導線**：商品ごとに導線スコア（プロフィールのリンク・固定投稿・CTA・投稿数など）を点検し、営業AIがプロフィール文・固定投稿案を作成

### 予約投稿の実行係（別のターミナルで動かしておく）
```bash
cd ~/ando-seikotsu-ibaraki/ait-revenue-os
source .venv/bin/activate
python scheduler.py
```
1分ごとに予約を確認して投稿し、6時間ごとに反応数を同期、7日ごとにトークンを更新します。Mac がスリープ中は動かないので、投稿時刻にはMacを起こしておいてください。

### 画面ごとの使い方

1. **サンプルで操作を覚える**：左下「サンプルデータ」→「サンプルを投入」。🧪 マークが付いたデータはすべて架空です。
2. **市場調査**：テーマを登録 →「需要の仮説」をAIに出させる → 自分で調べて出典URLを登録 → 確認できたことだけ「確認済みの事実」に書く。
3. **note商品管理**：調査テーマから商品企画のたたき台を作る → 原稿を書く → 下書きをコンテンツ管理へ送る。
4. **楽天商品管理**（手動登録モード）：楽天の画面で確認した価格・報酬率・在庫を、**出典URLと確認日時つき**で登録する。
5. **コンテンツ管理**：Threads・X・note の下書きを作る（AI可）→ 品質チェック → 「レビューに出す」。
6. **承認キュー**：チェックリストをすべて確認して「承認」→ **各サービスで自分で公開** → 公開URLを入力して「公開済みとして記録」。
7. **売上CSVインポート**：note・楽天の管理画面からCSVをダウンロード → 列を対応付けて取り込む（重複は自動でスキップ）。
8. **部門ボード**：部門（AI社員）ごとの稼働状況・要対応・タスク（未着手→進行中→完了）・活動ログを一覧で管理。
9. **経営ダッシュボード**：売上・件数・CTR・CVR・費用・粗利益を確認。CTR/CVRの元になる表示回数・クリック数は手入力します。
10. **チャド日次報告**：毎日「日次報告を作成」→ 実績・改善提案・優先タスク3つ。

本番運用を始めるときは、サイドバーの「サンプルを削除」でサンプルを消してください。

## 3. 費用と制約

| 項目 | 内容 |
|---|---|
| アプリ本体 | 無料（自分のMacで動作。データは `data/ait_revenue.db` に保存） |
| AI生成 | Anthropic API の従量課金。既定モデル `claude-opus-5-5`（入力 $4／出力 $20 ・100万トークンあたり） |
| 1回あたりの目安 | 生成内容により **約5〜20円**（考える過程のトークンも出力として課金されます）。実際の金額は Anthropic の請求画面で確認してください |
| Threads API | 無料（Meta 公式）。投稿上限は公式 24時間250件、本アプリの既定は1日5件・60分間隔 |
| 予算の上限 | `.env` の `AIT_AI_DAILY_BUDGET_YEN`（既定 300円/日）を超えると自動でテンプレート生成に切り替え |
| 為替 | 費用の円換算は `.env` の `AIT_USD_JPY`（既定150）で計算した**推定値** |

**やらないこと（意図的な制約）**
- note・楽天・X への投稿、公開、価格・販売設定の変更（Threads は承認＋予約したものだけ公式APIで投稿）
- 承認なしの自動投稿、返信・DM・フォロー・いいね等の自動操作
- 楽天APIとの連携（公式仕様・規約を確認してから追加予定。現在は手動登録モード）
- Webページの自動取得（スクレイピング）、ブラウザの自動操作
- DMでのアフィリエイトリンク送付、自動の大量投稿

## 4. 困ったとき

| 症状 | 対処 |
|---|---|
| `command not found: streamlit` | `source .venv/bin/activate` を実行してから起動してください |
| AIが「テンプレートで作成しました」と出る | `.env` のAPIキーを確認。予算上限・通信エラーの場合も同じ表示になります（ダッシュボードの「AI利用履歴」で理由を確認できます） |
| CSVが読めない | 文字コード（UTF-8／Shift_JIS）は自動判定します。列の対応付けで必須項目（日付と金額）を選んでください |
| データを最初からやり直したい | アプリを止めて `data/ait_revenue.db` を削除し、再起動します（**本番データも消えます**） |
