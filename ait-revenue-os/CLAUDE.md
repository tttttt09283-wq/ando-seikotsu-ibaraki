# CLAUDE.md — A.I.T Revenue OS 開発ルール

このフォルダ（`ait-revenue-os/`）で作業する AI 開発者向けのルール。

## 絶対に守ること
- 外部サービス（note・楽天・X・Threads ほか）への投稿・公開・販売設定変更のコードを書かない。
- 公式APIの仕様が確認できない連携、スクレイピング、ブラウザ自動操作を実装しない（手動モードにする）。
- 承認・公開記録は人間（`workflow.HUMAN_ACTOR`）だけ。承認処理に公開処理を混ぜない。
- 架空のレビュー・使用体験・売上・効果・URL・出典を生成させない／サンプル以外で作らない。
- AIの仮説と確認済みの事実を同じ欄に混ぜない。
- 価格・在庫・報酬率は出典URLと確認日時をセットで保存する。
- APIキー等は `.env` のみ。コード・DB・ログ・テストに書かない。
- DMでのアフィリエイトリンク送付、スパム的な投稿機能を実装しない。

## 実装の約束
- 金額は円の整数（`int`）。浮動小数で売上を持たない。
- DB変更は `db.py` の `MIGRATIONS` に新しい番号で追加する（既存の手順は変更しない）。
- Claude API 呼び出しは `revenue_os/ai/client.py` の `generate()` だけを通す（予算・記録・テンプレート切替が入っている）。
- 画面（`ui/`）にロジックを書かない。業務ロジックは `revenue_os/` 直下のモジュールに置き、テストを書く。
- UI 文言は日本語で、初心者に分かる言葉にする。
- 日時はローカル時刻（`datetime.now`）で保存する。

## 確認コマンド
```bash
source .venv/bin/activate
pytest
streamlit run app.py
```
