# 03. MVP 画面構成・画面一覧

## 1. ナビゲーション（スマートフォン優先）

画面下部に固定タブバー（5項目）。PC では左サイドバーに切替。

```
┌───────────────────────────┐
│ A.I.T Follow Manager  [店舗▼]│ ← 店舗切替（複数店舗所属時）
├───────────────────────────┤
│                           │
│        コンテンツ          │
│                           │
├─────┬─────┬─────┬─────┬─────┤
│ホーム│タスク│ 顧客 │テンプレ│その他│
└─────┴─────┴─────┴─────┴─────┘
```

「その他」＝ 分析 / 設定 / 組織切替 / ログアウト

## 2. 主要動線（タップ数）

**フォロー対応（最重要）**：ホーム →（1）今日のタスク → （2）タスク → （3）「文面をコピー」
→ 外部ツールで送信 → （4）「対応済み」→ （5）結果チップ選択（電話つながった／LINE送信済み 等）＝ **5タップ**

**顧客検索**：顧客タブ →（1）検索欄に入力 → （2）顧客をタップ ＝ **2タップ＋入力**

**配信停止の記録**：顧客詳細 → （1）連絡同意 → （2）「配信停止にする」→（3）確認 ＝ **3タップ**

## 3. タスクの優先度表示

| 状態 | 表示 |
|---|---|
| 期限切れ | 左端に赤ライン＋「期限切れ ○日」バッジ（最上部に並ぶ） |
| 今日が期限 | 青ライン＋「今日」バッジ |
| 期限内 | ライン無し、期限日を表示 |
| 保留 | グレー表示、「保留」バッジ |
| ルール優先度 高 | ★アイコン（同じ期限内で上位に並ぶ） |

色だけに頼らず、必ずテキストバッジを併記する。

## 4. 画面一覧

ルートは Next.js App Router。組織はURLに含める（`/o/[orgSlug]/...`）ことで、
複数組織所属時の取り違えを防ぎ、サーバー側で毎回所属を検証する。

### 4.1 認証（未ログイン）

| ID | 画面 | パス | 備考 |
|---|---|---|---|
| A-01 | ログイン | `/login` | |
| A-02 | パスワード再設定申請 | `/forgot-password` | |
| A-03 | パスワード再設定 | `/reset-password` | |
| A-04 | 招待受諾・初期パスワード設定 | `/invite/[token]` | |
| A-05 | MFA 設定・確認 | `/mfa` | 管理者ロールは必須 |
| A-06 | 組織選択 | `/select-org` | 複数組織所属時のみ |

## 5. デザイントークン

| トークン | 値 | 用途 |
|---|---|---|
| `--navy` | `#0F1E3D` | ヘッダー・主要テキスト |
| `--blue` | `#2563EB` | アクセント・主要ボタン・「今日」 |
| `--bg` | `#FFFFFF` / `#F7F8FA` | 背景 |
| `--danger` | `#DC2626` | 期限切れ・連絡不可 |
| `--muted` | `#6B7280` | 保留・補足 |
