# 01. 要件の不明点と推奨デフォルト

各項目に **推奨デフォルト** を記載しています。回答がない項目は推奨デフォルトで進めます。
「要承認」は、費用・外部影響が発生するため、回答なしでは着手しない項目です。

## A. 進め方・環境（要承認を含む）

| # | 質問 | 推奨デフォルト | 区分 |
|---|---|---|---|
| Q1 | 開発リポジトリはどこにしますか？ 現在のリポジトリは安藤整骨院のシステムです。 | **専用リポジトリ（例：`ait-follow-manager`）を新規作成**。作成までは本ディレクトリで設計・開発し、後で履歴ごと移設 | 要回答 |
| Q2 | Supabase プロジェクトは新規作成してよいですか？（開発・本番の2つ。既存の整骨院用プロジェクトとは**完全に分離**） | 開発用を Free で作成、本番用は試験運用前に Pro で作成 | **要承認**（費用） |
| Q3 | バックアップ方式：Supabase Pro の日次バックアップで足りますか？ PITR（任意時点復元）は追加費用です。 | 本番は Pro の日次バックアップ＋週次の論理ダンプを別ストレージへ保存。PITR は契約企業数に応じて検討 | **要承認**（費用） |
| Q4 | Vercel は既存チームに新規プロジェクトとして作成してよいですか？ | 新規プロジェクト。Preview＝開発DB、Production＝本番DB | **要承認** |
| Q5 | 独自ドメインの予定はありますか？ | 当面は `*.vercel.app`。販売開始前に決定 | 任意 |

## B. 業務ルール

| # | 質問 | 推奨デフォルト |
|---|---|---|
| Q6 | 連絡同意が**未確認**（記録なし）の顧客は、連絡タスクの対象にしますか？ | **対象外**にし、「同意確認が必要」一覧に表示。組織設定で「未確認も対象にする」へ切替可能（初期値OFF） |
| Q7 | Staff が閲覧できる顧客の範囲は？ | **所属店舗の全顧客**（小規模店舗では担当外対応が多いため）。組織設定で「担当顧客のみ」へ切替可能 |
| Q8 | 1人のスタッフが複数店舗・複数企業に所属することはありますか？ | 複数店舗：あり。複数企業：あり（データモデルで対応、UIは組織切替） |
| Q9 | 顧客番号は自動採番ですか、既存の番号を使いますか？ | 組織内で一意。未入力なら自動採番（例：`C000123`）、CSV取込時は既存番号を優先 |
| Q10 | 来店履歴・予約データはどう入力しますか？ | Phase 1 は**手入力＋CSV取込**のみ。予約システム・POS との自動連携は対象外 |
| Q11 | 対応期限は定休日・営業日を考慮しますか？ | Phase 1 は暦日。店舗の定休日設定は Phase 1.5 で検討 |
| Q12 | フォロー条件が解消した場合（例：最終来店タスク生成後に再来店）、未対応タスクを自動で「対象外」にしますか？ | **自動で対象外**（理由：条件解消）にする。履歴は残す |
| Q13 | 1顧客に同時に複数の未対応タスクを持たせますか？ | 許可。ただし同一顧客の未対応タスクはタスク一覧でグループ表示し、重複連絡を防ぐ |
| Q14 | 「季節のご挨拶」はタスクとして自動生成しますか？ | Phase 1 は**テンプレートのみ**（自動生成なし）。顧客一覧の絞り込み結果から手動で一括タスク作成できる機能を用意 |
| Q15 | テンプレートで使える差し込み変数は？ | `{{顧客名}}` `{{店舗名}}` `{{担当者名}}` `{{次回予約日}}` の4つ |
| Q16 | 来店履歴に「施術内容」「メモ」を入れたいという要望が出た場合は？ | 標準項目は「来店日・店舗・担当・メニュー名（任意・自由入力）」まで。**症状・医療情報は入力欄を設けない**。メモ欄に注意書きを表示 |

## C. セキュリティ・運用

| # | 質問 | 推奨デフォルト |
|---|---|---|
| Q17 | ログイン方式は？ | メール＋パスワード（Supabase Auth）。**Organization Admin 以上は MFA（TOTP）必須**、その他は任意 |
| Q18 | スタッフの追加方法は？ | 管理者がメール招待 → 本人がパスワード設定。共有アカウントは禁止 |
| Q19 | Platform Admin がサポートのため顧客情報を見る必要はありますか？ | **原則不可**。必要時は Organization Admin が期限付きで「サポートアクセス」を許可する仕組み（Phase 1 は設計のみ、実装は Phase 1.5） |
| Q20 | 顧客データの保持期間・削除方針は？ | 削除依頼時は個人情報を匿名化（統計用の件数は残す）。退会企業のデータは解約後90日で完全削除 |
| Q21 | 監査ログの保持期間は？ | 1年（以降はアーカイブ） |
| Q22 | CSV の文字コードは？ | UTF-8 と Shift_JIS（Excel 保存形式）の両方に対応 |
