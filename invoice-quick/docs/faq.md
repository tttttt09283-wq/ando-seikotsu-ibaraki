## 導入・承認について

### Q. 「このアプリは Google で確認されていません」と出ます。危険ではないですか？

個人が作成した Google Apps Script では **必ず表示される定型の警告** です。
本ツールはあなたのスプレッドシートにコピーされたプログラムで、**あなたのアカウントの中だけで動作** します。
外部サーバーへの送信処理はなく、販売者があなたのデータを見ることもできません。
「詳細」→「（安全ではないページ）に移動」→「許可」で進めてください（[導入マニュアル](setup-guide.md#重要googleの承認画面の進め方) 参照）。

### Q. メニュー「Invoice Quick」が表示されません。

1. ブラウザを再読み込み（F5 / ⌘+R）してください。表示まで数秒かかることがあります。
2. スマートフォンアプリでは独自メニューは表示されません。**PCのブラウザ** で開いてください。
3. 手動でコードを貼り付けた場合は、Apps Script エディタで **保存（💾）** したか確認してください。

### Q. 会社のGoogleアカウントで「ブロックされています」と表示されます。

組織の管理者が Apps Script の利用を制限しています。個人の Google アカウント（@gmail.com）でご利用いただくか、管理者にご相談ください。

### Q. 無料のGoogleアカウントで使えますか？

はい。無料の個人アカウントで動作します。月額費用や追加の登録は必要ありません。
Google のサービスには1日あたりの利用上限がありますが、個人事業主の通常の発行件数（1日数十件程度）で問題になることはまずありません。

### Q. 複数のパソコンで使えますか？

はい。Google ドライブ上のスプレッドシートなので、同じ Google アカウントでログインすればどのPCからでも使えます。

### Q. 家族やスタッフと共有できますか？

スプレッドシートを「編集者」として共有すれば一緒に使えます。共有相手も初回に承認が必要です。
同時に2人がPDF作成ボタンを押しても、**排他制御（LockService）** により1件ずつ順番に処理されるため、番号の二重発行は起きません。
※PDFの保存先フォルダも共有相手が編集できるよう共有してください。

## 使い方について

### Q. 請求書番号はどのように決まりますか？

メニュー「🆕 新しい請求書を準備」で **「接頭辞＋年月＋連番」**（例：`INV-202610-001`）が自動で入ります。
連番は「発行履歴」をもとに、同じ年月の最大番号＋1になります。手入力で自由な番号にすることもできます。

### Q. 同じ番号で作成しようとしたら警告が出ました。

二重発行を防ぐための確認です。
- **別の書類の場合** →［いいえ］を押して番号を変更してください。
- **同じ書類を修正して出し直す場合** →［はい］で作成できます（発行履歴に「再発行」と記録されます）。

### Q. 発行した書類を取り消したいです。

「発行履歴」シートの該当行のステータスを **「取消」** に変更してください（行がグレーの取り消し線になります）。
取消にした番号は、警告なしで同じ番号を再利用できます。PDFファイルはドライブから手動で削除してください。

### Q. PDFはどこに保存されますか？

Google ドライブの「**Invoice Quick 発行書類 / 請求書（または見積書） / 2026年**」フォルダです。
ファイル名は `請求書_発行日_顧客名_請求書番号.pdf` です。ファイル名に使えない記号（`/ \ : * ? " < > |`）は自動で `_` に置き換えられます。

### Q. メールを自動送信できますか？

安全のため、自動送信は行いません（誤送信防止と、Gmail の権限を求めないため）。
完了画面の「本文をコピー」または「Gmailで下書きを開く」をご利用ください。PDFは「PDFを開く」からダウンロードして添付します。

### Q. 明細は何行まで入力できますか？

1枚あたり **最大20行** です。それ以上ある場合は、品名を「〇〇一式」とまとめるか、書類を分けてください。

### Q. 入力シートの数式を消してしまいました／レイアウトが崩れました。

メニュー「🛠 設定・メンテナンス」→「**入力シートを初期状態に戻す**」で修復できます。
初期設定・顧客マスタ・発行履歴・作成済みのPDFは消えません（入力中の内容のみクリアされます）。

### Q. 顧客マスタにない宛先へ1回だけ請求したいです。

顧客マスタに1行追加してください（使い終わったら削除してもOKです。発行履歴には顧客名が残ります）。

## 金額計算について

### Q. どのような計算ルールですか？

| 手順 | 内容 |
|---|---|
| ① 明細金額 | 数量 × 単価（税抜）。1円未満は「端数処理」設定に従う |
| ② 税率別の合計 | 10% / 8% / 0% ごとに明細金額を合計 |
| ③ 消費税 | 税率別の合計 × 税率。**端数処理は税率ごとに1回だけ** |
| ④ 合計（税込） | 小計（税抜）＋ 消費税合計 |
| ⑤ 源泉徴収（任意） | 小計（税抜）× 10.21%（100万円超の部分は20.42%）、1円未満切り捨て |
| ⑥ ご請求金額 | 合計（税込）− 源泉徴収税額 |

### Q. 明細ごとに消費税を計算しないのはなぜですか？

インボイス制度（適格請求書）では、**消費税の端数処理は「1つの請求書につき、税率ごとに1回」** と定められているためです。
明細ごとに端数処理して合計する方法は認められていません。

> 例：333円の明細が3行（10%）、端数処理が四捨五入の場合
> ✅ 正しい計算：999円 × 10% = 99.9円 → **100円**
> ❌ 明細ごと：33.3円→33円 × 3行 = 99円

### Q. 端数処理はどれを選べばいいですか？

法令上はどれを選んでも構いません。一般的には **「切り捨て」**（初期値）が多く使われています。取引先と取り決めがある場合はそれに合わせてください。

### Q. シートの合計と、PDFの金額が違うことはありますか？

シートの灰色の合計欄は「プレビュー」で、PDF作成時にはスクリプトが **同じルールで再計算し、さらに検算（セルフチェック）** してから作成します。
スクリプトは小数を整数に変換して計算するため、表計算ソフト特有の小数誤差（例：0.07×100 = 7.000000000000001）の影響を受けません。
ごくまれに、極端な小数（小数4桁同士の掛け算など）でプレビューが1円ずれる可能性がありますが、**PDFの金額が正** です。

### Q. 値引きはどう入力しますか？

明細の単価をマイナス（例：`-5000`）で入力します。値引き行の税率は、値引き対象の商品と同じ税率を選んでください。
合計がマイナスや0円になる場合はPDFを作成できません。

### Q. 税込金額で入力できますか？

本ツールは **税抜入力** 専用です。税込価格しか分からない場合は、税抜価格に換算して入力してください（例：税込11,000円 → 税抜10,000円・税率10%）。

### Q. 小数の数量・単価は使えますか？

使えます（小数4桁まで）。例：作業時間 2.5時間、文字単価 1.2円。
明細金額の1円未満は、端数処理の設定に従って丸められます。

## インボイス制度（適格請求書）について

### Q. このツールで作った請求書は「適格請求書（インボイス）」になりますか？

「初期設定」に **適格請求書発行事業者の登録番号** を入力すると、次の記載事項を備えた書式で出力されます。

| 適格請求書の記載事項 | 本ツールでの対応 |
|---|---|
| ① 発行事業者の氏名または名称・登録番号 | 発行者名・登録番号（初期設定） |
| ② 取引年月日 | 発行日（※取引日が異なる場合は、件名や品名・備考に記載してください） |
| ③ 取引内容（軽減税率対象品目である旨） | 明細の品名、8%の品目に「※」と注記 |
| ④ 税率ごとに区分して合計した対価の額・適用税率 | 「10%対象（税抜）」「8%対象（税抜）」の欄 |
| ⑤ 税率ごとに区分した消費税額等 | 「消費税（10%）」「消費税（8%）」の欄（税率ごとに1回端数処理） |
| ⑥ 書類の交付を受ける事業者の氏名または名称 | 宛名（顧客マスタ） |

> ⚠️ 登録番号の **登録状況の確認や、記載内容が要件を満たすかの最終判断は、利用者ご自身の責任** で行ってください。
> 登録番号は国税庁「インボイス制度 適格請求書発行事業者公表サイト」で確認できます。

### Q. インボイス登録をしていません。使えますか？

使えます。登録番号を **空欄** にすると、登録番号の行が表示されない通常の請求書になります。

### Q. 登録番号を入れたらエラーになりました。

登録番号は **「T」＋13桁の数字** です（例：`T1234567890123`）。全角やハイフン入りで入力しても自動で整形されますが、桁数が違うとエラーになります。

### Q. 見積書にも登録番号は必要ですか？

見積書は適格請求書ではないため必須ではありませんが、入力していれば見積書にも表示されます。

## 源泉徴収について

### Q. 源泉徴収の欄は何ですか？

個人のデザイナー・ライター・講師などが、法人などから報酬を受け取る際に **源泉徴収** が必要な場合があります。
請求書入力シートの「源泉徴収」を **「する」** にすると、次のように計算して請求書に記載します。

- 対象額：小計（税抜）※請求書で消費税額を区分して記載しているため、税抜額が対象
- 100万円以下の部分：10.21%、100万円を超える部分：20.42%（1円未満切り捨て）
- ご請求金額 = 合計（税込）− 源泉徴収税額

### Q. 自分の取引が源泉徴収の対象か分かりません。

源泉徴収の要否は、報酬の種類や支払者（法人・個人）によって異なります。**取引先の経理担当者、税理士、または税務署にご確認ください。**
交通費などの立替金を明細に含めた場合も、本ツールは小計全体を対象として計算します。立替金を対象外とすべき取引では、別の請求書に分けるなどの対応をご検討ください。

## テンプレート・デザインについて

### Q. ロゴを入れたり、デザインを変えたりできますか？

できます。テンプレートは普通の Googleドキュメントです。ドライブの「Invoice Quick 発行書類 / テンプレート」にある「Invoice Quick 請求書テンプレート」を開いて、ロゴの挿入・色・フォント・文章を自由に変更してください。
`{{ }}` の差し込み記号を消さないようにご注意ください。

### Q. テンプレートの差し込み記号の一覧は？

| 記号 | 内容 | 備考 |
|---|---|---|
| `{{請求書番号}}` / `{{見積書番号}}` | 書類番号 | |
| `{{発行日}}` | 発行日（例：2026年10月17日） | |
| `{{支払期限}}` / `{{有効期限}}` | 期限 | |
| `{{宛先1}}` `{{宛先2}}` | 宛名（会社名＋御中 / 会社名＋担当者 様） | 宛先2は空なら行ごと削除 |
| `{{顧客郵便番号}}` `{{顧客住所}}` | 顧客の住所 | 空なら行ごと削除 |
| `{{発行者名}}` `{{発行者郵便番号}}` `{{発行者住所}}` `{{発行者電話}}` `{{発行者メール}}` | 発行者情報 | 空なら行ごと削除（発行者名以外） |
| `{{登録番号}}` | 適格請求書発行事業者 登録番号 | 空なら行ごと削除 |
| `{{件名}}` | 件名 | 空なら行ごと削除 |
| `{{ご請求金額}}` / `{{見積金額}}` | 大きく表示する金額（例：¥110,000-） | |
| `{{品名}}` `{{数量}}` `{{単価}}` `{{税率}}` `{{金額}}` | 明細表 | `{{品名}}` を含む表の行が明細の数だけ複製されます |
| `{{小計}}` `{{消費税合計}}` `{{合計}}` | 合計欄 | |
| `{{内訳10_対象}}` `{{内訳10_税}}` | 10%対象額・消費税 | 10%の明細がない場合は表の行ごと削除 |
| `{{内訳8_対象}}` `{{内訳8_税}}` | 8%対象額・消費税 | 8%の明細がない場合は表の行ごと削除 |
| `{{内訳0_対象}}` | 0%対象額 | 0%の明細がない場合は表の行ごと削除 |
| `{{源泉_税額}}` `{{源泉_差引}}` | 源泉徴収税額・差引請求額（請求書のみ） | 源泉徴収なしの場合は表の行ごと削除 |
| `{{軽減税率注記}}` | 「※印は軽減税率（8%）対象品目です。」 | 8%の明細がない場合は行ごと削除 |
| `{{振込先見出し}}` `{{振込先}}` | 振込先（請求書のみ） | 空なら行ごと削除 |
| `{{見積条件見出し}}` `{{見積条件}}` | 見積条件（見積書のみ） | 空なら行ごと削除 |
| `{{備考見出し}}` `{{備考}}` | 備考 | 空なら行ごと削除 |

> 一覧にない記号（入力ミスなど）は空欄に置き換えられ、完了画面に注意が表示されます。

### Q. テンプレートが崩れてしまいました。

メニュー「🛠 設定・メンテナンス」→「**書類テンプレートを再作成**」で、初期デザインのテンプレートが新しく作られます（古いテンプレートは削除されずに残ります）。

## エラーメッセージ別の対処法

エラーが出たときは、**メッセージに表示された「シート名」と「セル」を修正** してください。該当セルは自動で選択されます。

### 入力内容のエラー

| メッセージ（抜粋） | 原因と対処 |
|---|---|
| 「初期設定」の発行者名を入力してください | 初期設定シートの発行者名が空欄です |
| 登録番号は「T＋13桁の数字」で入力してください | 登録番号の桁数を確認。未登録なら空欄に |
| 〇〇テンプレートが未作成です | 「⚙️ 初期セットアップ」を実行してください |
| 請求書番号を入力してください | 「🆕 新しい請求書を準備」で自動採番できます |
| 支払期限が発行日より前になっています | 日付を確認してください |
| 顧客IDを▼から選んでください | 顧客IDが空欄です |
| 顧客ID「〇〇」が「顧客マスタ」に見つかりません | 顧客マスタで削除・変更されていないか確認 |
| 顧客ID「〇〇」が顧客マスタに2件あります | 顧客IDが重複しています。どちらかを別のIDに変更 |
| 明細〇行目：品名を入力してください | 数量・単価だけが入っている行があります |
| 明細〇行目：数量は数字で入力してください | 「1式」などの文字は品名に入れ、数量は「1」に |
| 明細〇行目：税率は 10・8・0 のいずれかを選んでください | ▼から選び直してください |
| 明細を1行以上入力してください | 明細が空です |
| 合計金額がマイナス／0円です | 値引き行・数量・単価を確認してください |

### 処理中のエラー

| メッセージ（抜粋） | 原因と対処 |
|---|---|
| 同じ番号の請求書が発行済みです | [二重発行の確認](#q-同じ番号で作成しようとしたら警告が出ました) をご覧ください |
| 別の書類を作成中です | 前の処理が終わるまで待ってから実行してください（連続クリック防止） |
| PDF保存先フォルダにアクセスできません | フォルダIDが正しいか確認。空欄にして「⚙️ 初期セットアップ」を実行すると新しく作成されます |
| テンプレートが見つかりません | 「🛠 設定・メンテナンス」→「書類テンプレートを再作成」 |
| 「発行履歴」への記録に失敗したため、PDFを削除しました | 発行履歴シートが削除・保護されていないか確認し、再実行。**履歴に記録されなかったPDFは自動で削除** されるため、二重発行にはなりません |
| シート「〇〇」が見つかりません | シート名を変更した場合は元に戻すか、「⚙️ 初期セットアップ」を実行 |

### エラーコード付きのメッセージ

| コード | 内容 | 対処 |
|---|---|---|
| E101 | フォルダ・テンプレートが見つからない | フォルダIDを空欄にして初期セットアップ、またはテンプレートを再作成 |
| E102 | 権限不足 | メニューから再実行し、承認画面で「許可」。共有フォルダの場合は編集権限を確認 |
| E103 | Google の利用上限 | 時間をおいて（翌日以降）再実行 |
| E104 | 処理時間の超過 | 1〜2分おいて再実行。PDFが重複していないか発行履歴とドライブを確認 |
| E105 | ドライブの容量不足 | 不要なファイルを削除 |
| E199 | その他のエラー | ページを再読み込みして再実行。解決しない場合は「入力シートを初期状態に戻す」 |

> PDFの作成途中でエラーになった場合、**発行履歴には記録されません**（成功した書類だけが記録されます）。作業用の一時ファイルも自動で削除されます。

## セキュリティ・プライバシー

### Q. 入力した顧客情報や口座情報は、どこかに送信されますか？

**送信されません。** すべての処理はあなたの Google アカウント内（スプレッドシート・ドキュメント・ドライブ）で完結します。外部のAPIやサーバーは使用していません。

### Q. ログに個人情報が残りませんか？

エラー時のログ（Apps Script の実行ログ）には、エラーコードと処理名だけを記録し、**入力値・顧客名・口座番号などの内容は記録しない** 設計にしています。

### Q. 販売者が私のデータを見ることはできますか？

できません。コピーしたスプレッドシートとプログラムはあなたの所有物になり、販売者には共有されません。
