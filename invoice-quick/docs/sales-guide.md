### ▼ ここから記事本文（無料部分）

**請求書づくり、毎回ゼロからやっていませんか？**

- 前回の請求書をコピーして、日付と金額を書き換える
- 電卓で消費税を計算して、合計が合っているか不安になる
- 「請求書番号、前回いくつだっけ？」と過去のファイルを探す
- PDFにして、ファイル名を付けて、メールの文面を考えて……

私も【フリーランスになって最初の1年】、毎月末に【2〜3時間】をこの作業に使っていました。
しかも、インボイス制度が始まってから「税率ごとの消費税」「登録番号の記載」など、気にすることが増えましたよね。

そこで作ったのが、**Googleスプレッドシートで請求書・見積書をワンクリックでPDFにできるテンプレート「Invoice Quick」** です。

---

#### Invoice Quick でできること

**① 入力して、メニューを1回押すだけ**

取引先を▼で選んで、品名・数量・単価を入れたら、メニューの「請求書PDFを作成」を押すだけ。
数秒で、きれいなレイアウトの請求書PDFがGoogleドライブに保存されます。

【画像：入力画面 → 完成したPDF の Before/After】

**② 消費税の計算はおまかせ（インボイス制度のルールに対応）**

- 10% / 8%（軽減税率）/ 0% の明細が混ざっていてもOK
- 消費税は **「税率ごとに1回だけ端数処理」**（インボイス制度のルール）
- 端数処理は「切り捨て・四捨五入・切り上げ」から選べる
- 登録番号を入れておけば、毎回自動で記載
- 軽減税率の品目には「※」を自動で付けて注記

**③ 送信用のメール文面も自動で作成**

PDFができると同時に、宛名・金額・支払期限・振込先が入ったメール文面が表示されます。
「コピー」ボタンか「Gmailで下書きを開く」で、そのまま送れます。

【画像：完了画面（PDFリンク＋メール文面）】

**④ うっかりミスを防ぐ仕組み**

- 必須項目の入れ忘れは、**どのセルを直せばいいか** を日本語で案内
- 同じ請求書番号で作ろうとすると **二重発行の警告**
- 番号は「INV-202610-001」のように **自動採番**
- PDFを作る前に **金額を自動で検算**

**⑤ 見積書もセットで使える**

見積書も同じ操作で作成できます。受注したら「見積書 → 請求書へ転記」ボタンで、明細を打ち直す必要もありません。

**⑥ 発行履歴が自動で残る**

いつ・誰に・いくら請求したかが一覧で残り、PDFへのリンクから過去の書類をすぐ開けます。

---

#### 使い方は3ステップ

```
① 新しい請求書を準備（番号・日付が自動で入る）
② 取引先を選んで、明細を入力
③ 「請求書PDFを作成」を押す → 完成！
```

初回の設定は、マニュアルに沿って **約5分** が目安です。プログラミングの知識はいりません。

---

#### こんな方におすすめです

- 毎月の請求書を手作業（Word・Excel・前回のコピー）で作っている
- 請求書の作成サービスを検討したけど、**月額費用をかけるほどの件数ではない**
- インボイス制度の計算ルールに沿った請求書を、手軽に作りたい
- SNS運用代行・デザイン・ライティングなど、**毎月同じ取引先に請求** している
- 副業を始めたばかりで、まずは請求書の型を整えたい

#### 向いていない方

- 1か月に数百件の請求書を発行する（会計ソフトや専用サービスがおすすめです）
- 会計ソフトとの自動連携や、入金の消し込みまで自動化したい
- スマートフォンだけで請求書を作りたい（作成はPCで行います）

| データの保存先 | 自分のPC | サービスの会社 | **自分のGoogleドライブ** |
| デザインの変更 | 自由 | テンプレートから選択 | **自由（Googleドキュメントで編集）** |

#### よくある質問

**Q. 無料のGoogleアカウントで使えますか？**
A. はい。無料の個人アカウントで動きます。月額費用もかかりません。

**Q. パソコンが苦手でも大丈夫ですか？**
A. 手順を1つずつ解説したマニュアルの通りに進めれば、5分ほどで設定できます。初回だけ表示されるGoogleの確認画面（「このアプリはGoogleで確認されていません」）の進め方も、丁寧に解説しています。

**Q. 入力したデータはどこに保存されますか？**
A. すべてあなたのGoogleドライブの中です。外部のサーバーには送信されず、販売者が見ることもできません。

**Q. インボイスの登録をしていなくても使えますか？**
A. 使えます。登録番号を空欄にすると、登録番号のない通常の請求書になります。

**Q. ロゴを入れられますか？**
A. はい。テンプレートは普通のGoogleドキュメントなので、ロゴや色、文章を自由に変更できます。

## 4. 30秒デモ動画の撮影台本

画面録画（PCの画面）＋テロップで作ります。BGMは控えめに。縦型（9:16）で撮る場合は、スプレッドシートを拡大表示して入力部分だけを映します。

| 秒 | 画面 | テロップ |
|---|---|---|
| 0〜3 | 手作業で請求書を書き換えている画面（早送り） | 請求書、毎回ゼロから作ってない？ |
| 3〜6 | メニュー「🆕 新しい請求書を準備」をクリック → 番号・日付が自動で入る | 番号と日付は自動 |
| 6〜10 | 顧客IDを▼で選ぶ → 顧客名・住所が自動表示 | 取引先は▼で選ぶだけ |
| 10〜16 | 明細を2〜3行入力 → 合計欄が自動計算される | 消費税も税率ごとに自動計算 |
| 16〜19 | メニュー「📄 請求書PDFを作成」をクリック | 押すのは1回だけ |
| 19〜24 | 完了画面 →「PDFを開く」→ 完成したPDF | 数秒でPDFが完成 |
| 24〜28 | 「本文をコピー」→ メール文面 | 送信用メールも自動 |
| 28〜30 | ロゴ・商品名 | 月額0円｜Invoice Quick |

### 撮影のコツ

- 顧客名・住所・口座番号は **サンプルデータ** を使う（実在の取引先や自分の口座を映さない）
- ブラウザのブックマークバー・他のタブは非表示にする
- マウスカーソルを大きめに設定すると見やすい
- 処理を待つ部分（PDF作成中）はカットして短くする。**実際の処理時間を誤解させない** よう「※実際の処理時間は数秒〜10秒程度」と小さく表示

## 5. 販売前チェックリスト（配布用テンプレートの作り方）

購入者に「コピー用リンク」を渡すためのマスターファイルを作ります。

### ① マスターファイルを作る

- [ ] 販売用のGoogleアカウント（個人用と分けるのがおすすめ）で新しいスプレッドシートを作成
- [ ] ファイル名を「Invoice Quick」に変更
- [ ] 「拡張機能」→「Apps Script」で `src/` の10個の `.gs` ファイルと `appsscript.json` を貼り付けて保存
- [ ] スプレッドシートを再読み込みし、「⚙️ 初期セットアップ」を実行
- [ ] テストデータで請求書・見積書を作成し、PDFの内容・金額・メール文面を確認
- [ ] 10% / 8% / 0% の混在、値引き、源泉徴収あり、の各パターンで金額を確認

### ② 配布用に個人情報を消す

- [ ] Apps Script エディタで関数 `prepareForDistribution` を選んで ▶ 実行
  - 初期設定の個人情報・テンプレートID・フォルダIDを消去
  - 発行履歴を消去
  - 顧客マスタをサンプルに戻す
  - 入力シートを初期状態に戻す
- [ ] 「初期設定」シートに自分の名前・口座が残っていないことを目で確認
- [ ] 「発行履歴」が空になっていることを確認
- [ ] ファイル → 版の履歴 に個人情報が残っている場合は、**確認済みの状態から新しいスプレッドシートにコピーし直したもの** を配布用にする

### ③ コピー用リンクを作る

- [ ] 共有 → 一般的なアクセス →「**リンクを知っている全員**」・権限「**閲覧者**」
- [ ] URLの末尾 `/edit#gid=0` などを `/copy` に置き換える
  - 例：`https://docs.google.com/spreadsheets/d/XXXXXXXX/copy`
- [ ] **別のGoogleアカウント（またはシークレットウィンドウ）** でリンクを開き、以下を確認
  - [ ] 「コピーを作成」画面が表示される
  - [ ] コピー後にメニュー「Invoice Quick」が表示される
  - [ ] 初期セットアップ → 承認 → PDF作成まで、マニュアル通りに進められる

### ④ note を公開する

- [ ] 有料エリアの位置が「▼ここから有料部分」になっている
- [ ] 有料部分にコピー用リンク・マニュアル・FAQを掲載
- [ ] 画像の個人情報（口座番号・住所・実在の取引先）にモザイク or サンプル化
- [ ] 価格：2,480円

> ⚠️ マスターファイル（コピー元）は **編集しない・削除しない** でください。リンクが使えなくなります。
> 更新版を出すときは、マスターファイルのコードを更新すれば、以後のコピーに反映されます（購入済みの方には更新手順を案内）。

## 6. 表現の注意（景品表示法・ステマ規制）

| 避ける表現 | 言い換え例 | 理由 |
|---|---|---|
| 「絶対にミスしない」「100%正確」 | 「ミスを防ぐ仕組み（必須チェック・二重発行の警告・自動検算）」 | 誇大表現（優良誤認）のおそれ |
| 「インボイス完全対応」「税務署も認めた」 | 「インボイス制度の記載事項・端数処理ルールに沿った書式」 | 公的な認定は受けていない |
| 「誰でも1分でできる」 | 「初回設定は約5分が目安、毎回の作成は約1分が目安」 | 個人差がある。「目安」と明記 |
| 「10秒でPDF」 | 「数秒〜10秒程度（通信環境により異なります）」 | 処理時間はGoogle側の状況で変わる |
| 「月額サービスより〇万円お得」 | 「月額費用はかかりません（買い切り）」 | 他社比較は根拠が必要 |
| 「税理士監修」 | （監修を受けていない場合は使わない） | 虚偽表示になる |

- 購入者の感想を紹介するときは、**本人の許可を取り、実際の感想をそのまま** 掲載します。
- 知人などに依頼して投稿してもらう場合は、**「PR」「広告」などの表示が必要** です（ステルスマーケティング規制）。
- 「残り〇本」「今だけ」などの限定表現は、事実と異なる場合に使わないでください。
