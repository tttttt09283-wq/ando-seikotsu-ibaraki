# Invoice Quick 導入マニュアル（5分セットアップ）

> **請求書づくり、毎回ゼロからやっていませんか？**
> このマニュアルの通りに進めれば、**約5分**で最初の請求書PDFが作れます。
> プログラミングの知識は必要ありません。

## 1. はじめに（必要なもの）

| 必要なもの | 説明 |
|---|---|
| Googleアカウント | 無料の個人アカウント（@gmail.com）で動きます。Google Workspace でもOK |
| パソコン | 初期設定と書類の作成は **PC（Chrome推奨）** で行ってください |
| 費用 | 購入代金のみ。**月額費用・外部サービスの登録は一切不要**です |

### 所要時間の目安

| ステップ | 内容 | 目安 |

| STEP 1 | テンプレートをコピー | 1分 |
| STEP 2 | 初期セットアップ（承認含む） | 1分 |
| STEP 3 | 自分の情報を入力 | 2分 |
| STEP 4 | 取引先を登録 | 30秒 |
| STEP 5 | 最初の請求書PDFを作成 | 30秒 |

## STEP 1：テンプレートをコピーする（1分）

1. PCのブラウザで Google にログインした状態にします。
2. 購入ページに記載の **「テンプレートのコピー用リンク」** を開きます。
3. 「**ドキュメントのコピーを作成しますか？**」と表示されたら、**［コピーを作成］** を押します。

   > 「添付の Apps Script ファイルもコピーされます」と表示されます。これが本ツールのプログラムです。そのまま進めてください。

4. 自分のGoogleドライブに「Invoice Quick のコピー」というスプレッドシートが作られ、自動で開きます。
   ファイル名は「請求書管理」など、分かりやすい名前に変更してOKです。

5. 数秒待つと、画面上部のメニューに **「Invoice Quick」** が表示されます。

> 💡 **メニューが表示されない場合**
> ブラウザを再読み込み（F5 キー / Mac は ⌘+R）してください。それでも表示されない場合は、10秒ほど待ってからもう一度再読み込みします。

---

## STEP 2：初期セットアップを実行する（1分）

1. メニュー **「Invoice Quick」→「⚙️ 初期セットアップ（最初に1回）」** をクリックします。
2. 初回だけ、Googleの **承認画面** が表示されます。
   → 次の「[承認画面の進め方](#重要googleの承認画面の進め方)」の通りに進めてください。
3. 承認が終わったら、**もう一度** メニュー「⚙️ 初期セットアップ（最初に1回）」をクリックします。
4. 確認メッセージで **［はい］** を押します。10〜30秒ほどで次のものが自動作成されます。

| 自動で作成されるもの | 場所 |
|---|---|
| 6つのシート（README / 初期設定 / 顧客マスタ / 請求書入力 / 見積書入力 / 発行履歴） | このスプレッドシート |
| 請求書テンプレート・見積書テンプレート（Googleドキュメント） | ドライブ「Invoice Quick 発行書類」→「テンプレート」 |
| PDFの保存先フォルダ | ドライブ「Invoice Quick 発行書類」 |

5. 「✅ セットアップが完了しました」と表示されたら完了です。

> 💡 初期セットアップは **何度実行しても大丈夫** です。入力済みのデータは消えず、足りないものだけが作られます。

## 【重要】Googleの承認画面の進め方

本ツールは、あなたのGoogleアカウント内で「PDFを作ってドライブに保存する」ために、**最初の1回だけ** 権限の許可が必要です。
画面は英語・日本語どちらの場合もあります。下の順番で進めてください。

### ① 「承認が必要です」

> 「このスクリプトを実行するには承認が必要です」

→ **［OK］**（または **［続行］**）を押します。

### ② アカウントの選択

→ **このスプレッドシートを使う自分のGoogleアカウント** を選びます。

### ③ 「このアプリは Google で確認されていません」

> ⚠️ 「Google hasn't verified this app」と表示されることもあります。

ここで止まってしまう方が多いですが、**故障やウイルスではありません**。

1. 画面左下の小さな文字 **「詳細」**（Advanced）をクリック
2. 下に出てくる **「Invoice Quick のコピー（安全ではないページ）に移動」**（Go to ... (unsafe)）をクリック

> **なぜこの警告が出るの？**
> 個人が作ったスクリプト（Google Apps Script）は、Google の審査を受けていないため、必ずこの表示が出ます。
> このスクリプトは **あなた自身のスプレッドシートの中にコピーされたもの** で、あなたのアカウントの権限でのみ動きます。
> 作成者（販売者）があなたのデータを見ることはできません。外部のサーバーにデータを送る処理もありません。

### ④ 権限の確認 → ［許可］

「Invoice Quick のコピー が Google アカウントへのアクセスをリクエストしています」と表示されます。

> 項目ごとにチェックボックスが表示される場合は、**「すべて選択」にチェック** を入れてから **［続行］** を押してください。
> チェックを外すと、PDFが作成できません。

求められる権限と、その理由は次の通りです。

| 表示される権限 | 何に使うか |
|---|---|
| このアプリケーションが表示されているスプレッドシートの表示と管理 | 入力内容の読み取り・発行履歴の記録（**このスプレッドシートだけ**） |
| Googleドキュメントの表示、編集、作成、削除 | 請求書・見積書テンプレートの作成と、差し込み処理 |
| Googleドライブのすべてのファイルの表示、編集、作成、削除 | テンプレートの複製、PDFの保存、作業用ファイルの削除 |
| サードパーティのウェブコンテンツをプロンプトやサイドバーで表示し、実行する | 完了画面（PDFリンク・メール文面）の表示 |

> ドライブの権限が「すべてのファイル」となっているのは、Google の仕組み上「フォルダにPDFを保存する」機能がこの権限の単位でしか用意されていないためです。本ツールが操作するのは、テンプレート・保存先フォルダ・作成したPDFだけです。

### ⑤ もう一度メニューから実行

承認が終わっても、最初のクリックで押した処理は実行されていないことがあります。
**もう一度メニューから「⚙️ 初期セットアップ」を実行** してください。

### 承認がうまくいかないとき

| 症状 | 対処 |
|---|---|
| 「詳細」が見当たらない | 画面を下までスクロールするか、ウィンドウを広げてください |
| 「このアプリはブロックされています」と出る | 会社・学校のGoogle Workspaceで管理者がスクリプトを禁止しています。個人のGoogleアカウント（@gmail.com）で利用するか、管理者にご相談ください |
| 複数のGoogleアカウントでログインしている | 別アカウントが選ばれてエラーになることがあります。**シークレットウィンドウ** で使うアカウントだけにログインして試してください |
| 承認画面が一瞬で消える／開かない | ブラウザのポップアップブロックを解除してください（アドレスバー右端のアイコン） |

## STEP 3：自分の情報を入力する（2分）

「**初期設定**」シートを開き、**黄色いセル** に入力します。赤い **＊** は必須です。

| 項目 | 入力例 | ポイント |
|---|---|---|
| 発行者名（屋号・氏名）＊ | 山田デザイン事務所 山田 太郎 | 書類の右上に表示 |
| 郵便番号 / 住所 | 123-4567 / 東京都渋谷区〇〇1-2-3 | 自宅住所を載せたくない場合は空欄でもOK |
| 電話番号 / メールアドレス | 090-1234-5678 / info@example.com | 空欄の項目は書類に表示されません |
| 適格請求書発行事業者 登録番号 | T1234567890123 | **インボイス登録している方のみ**。未登録なら空欄 |
| 振込先（銀行名〜口座名義） | 〇〇銀行 / 渋谷支店 / 普通 / 1234567 / ヤマダ タロウ | 請求書とメール文面に表示 |
| 消費税の端数処理＊ | 切り捨て | 迷ったら「切り捨て」（初期値） |
| 請求書番号の接頭辞 | INV- | 自動採番：INV-202610-001 |
| 支払期限の初期値 | 翌月末 | 「新しい請求書を準備」で自動入力 |
| 請求書の備考（初期値） | 振込手数料は〜 | 毎回同じ文言を入れたい場合に |
| メール署名 | （空欄） | 空欄なら発行者情報から自動作成 |

> 💡 セル内で改行するには **Ctrl + Enter**（Mac は **⌘ + Enter**）を押します。
> 💡 灰色のセル（テンプレートID など）はセットアップで自動入力されています。触らなくてOKです。

## STEP 4：取引先を登録する（30秒）

「**顧客マスタ**」シートに、取引先を1行に1社ずつ入力します。

| 列 | 入力例 | ポイント |
|---|---|---|
| 顧客ID＊ | C003 | 重複しない番号。「C001」「C002」…のように連番がおすすめ |
| 顧客名＊ | 株式会社〇〇 | 書類の宛名になります |
| 担当者 | 佐藤 花子 | 入力すると「株式会社〇〇／佐藤 花子 様」と表示 |
| 郵便番号・住所 | | 空欄でもOK |
| メール | sato@example.com | 送信用メール文面の宛先に使われます |
| 敬称 | 御中 / 様 | 担当者が空欄のときに使用（法人は御中、個人は様） |

> サンプル行（C001・C002）は、不要になったら **行ごと削除** してください。

## STEP 5：最初の請求書を作る（30秒）

1. 「**請求書入力**」シートを開きます（セットアップ直後は番号・日付が入っています）。
2. **顧客ID** のセルをクリックし、▼から取引先を選びます。
   → 顧客名・住所などが **灰色のセルに自動表示** されます。
3. **明細** に「品名・数量・単価（税抜）・税率」を入力します。
   → 金額・消費税・合計が **自動計算** されます。
4. メニュー **「Invoice Quick」→「📄 請求書PDFを作成」** をクリック。
5. 5〜10秒ほどで完了画面が表示されます。

| 完了画面のボタン | できること |
|---|---|
| PDFを開く | 作成したPDFを確認・ダウンロード |
| 本文をコピー | 送信用メール文面をコピー |
| Gmailで下書きを開く | 宛先・件名・本文が入った状態でGmailを開く（PDFは手動で添付） |

🎉 **これでセットアップは完了です！**
PDFはドライブの「Invoice Quick 発行書類 / 請求書 / 2026年」フォルダに、
`請求書_20261017_株式会社〇〇_INV-202610-001.pdf` のような名前で保存されます。

## 毎回の使い方

```
① メニュー「🆕 新しい請求書を準備」 … 番号・発行日・支払期限が自動で入る
② 顧客IDを選ぶ → 明細を入力
③ メニュー「📄 請求書PDFを作成」 … PDF保存＋メール文面が完成
```

### セルの色のルール

| 色 | 意味 |
|---|---|
| 🟨 淡い黄色 | 入力するセル |
| ⬜ 淡いグレー | 自動表示・自動計算（編集不要。誤って編集しようとすると警告が出ます） |
| 🟦 濃紺 | 見出し |
| 赤い ＊ | 必須項目 |

### 入力のコツ

- **金額はすべて税抜** で入力します。消費税は税率ごとに自動計算されます。
- **値引き** は、単価をマイナス（例：`-5000`）で入力します。
- **税率** は ▼ から「10（標準）」「8（軽減税率：飲食料品など）」「0（非課税・不課税）」を選びます。
- **小数** も使えます（例：2.5時間、1.2円/文字）。小数は4桁まで。
- **源泉徴収**（請求書のみ）：個人として報酬を受け取り、源泉徴収が必要な場合は「する」を選びます。

## 便利な機能

### 見積書を作る

「見積書入力」シートで同じように入力し、メニュー「📝 見積書PDFを作成」。
有効期限と見積条件（納期・支払条件など）も書類に記載されます。

### 見積書 → 請求書に転記

受注したら、メニュー「🔁 見積書の内容を請求書へ転記」で、顧客・件名・明細を請求書へコピーできます。
請求書番号・発行日・支払期限は新しく自動入力されます。

### メール文面だけ作り直す

「発行履歴」シートで対象の行をクリックしてから、メニュー「✉️ メール文面を作成（発行履歴の選択行）」。

### 発行履歴の使い方

| 状況 | 操作 |
|---|---|
| 同じ番号で作成しようとした | 「同じ番号の請求書が発行済みです」と警告が出ます。別の書類なら番号を変更、修正版の出し直しなら［はい］（履歴に「再発行」と記録） |
| 発行を取り消した | 発行履歴のステータスを「取消」に変更（行がグレー表示になります） |

### 保存先フォルダを変更する

「初期設定」の **PDF保存先フォルダID** に、保存したいフォルダのURLをそのまま貼り付けます（IDは自動で取り出されます）。
その中に「請求書 / 2026年」のようなフォルダが自動で作られます。

## 書類のデザインを変える（ロゴの追加など）

テンプレートは普通の Googleドキュメントなので、**自由に編集** できます。

1. 「初期設定」の **請求書テンプレートID** を確認（またはドライブ「Invoice Quick 発行書類 / テンプレート」を開く）
2. 「Invoice Quick 請求書テンプレート」を開いて編集
   - ロゴ画像の挿入（挿入 → 画像）
   - フォント・文字サイズ・色の変更
   - 固定の文章（「いつもありがとうございます」など）の追加
3. 保存は自動です。次回のPDFから反映されます。

> ⚠️ **`{{ }}` で囲まれた記号（差し込み記号）は消さないでください。** ここに実際の値が入ります。
> 差し込み記号の一覧は [FAQ「テンプレートの差し込み記号の一覧」](faq.md#q-テンプレートの差し込み記号の一覧は) をご覧ください。
> 崩れてしまったら、メニュー「🛠 設定・メンテナンス」→「書類テンプレートを再作成」で元に戻せます。

## 別の導入方法：コードを手動で貼り付ける

コピー用リンクが使えない場合や、自分のスプレッドシートに組み込みたい場合の方法です（10分程度）。

1. Googleドライブで **新しいスプレッドシート** を作成
2. メニュー **「拡張機能」→「Apps Script」** を開く
3. 左側「ファイル」の **＋ → スクリプト** で、次の10ファイルを作成し、同名ファイルの中身をそれぞれ貼り付け
   `Main` `Config` `Customer` `Calculator` `Validator` `History` `PdfGenerator` `Invoice` `Estimate` `Utils`
   （最初からある `コード.gs` は `Main` に名前を変更して使えます）
4. 左側の **⚙️「プロジェクトの設定」** →「**「appsscript.json」マニフェスト ファイルをエディタで表示する**」にチェック
   → エディタに表示された `appsscript.json` を、同梱の `appsscript.json` の内容で置き換え（タイムゾーンが日本時間になります）
5. 💾 保存（Ctrl+S）
6. スプレッドシートのタブに戻って **再読み込み** → メニュー「Invoice Quick」が表示されたら、[STEP 2](#step-2初期セットアップを実行する1分) へ

> 手順4は省略しても動作しますが、その場合はスクリプトのタイムゾーンを「(GMT+09:00) 日本標準時」に設定してください。

## アップデートの方法

新しいバージョンが公開された場合：

1. 「拡張機能」→「Apps Script」を開く
2. 更新されたファイルの中身を、新しいコードで置き換えて保存
3. スプレッドシートを再読み込みし、「⚙️ 初期セットアップ」を実行（追加された設定項目だけが追加されます）

> 初期設定・顧客マスタ・発行履歴・作成済みPDFは、そのまま引き継がれます。
